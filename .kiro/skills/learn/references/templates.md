# Output file layouts

## Guide: `agent-knowledge/{slug}.md`

Keep the headings so every guide in the knowledge base reads the same. Drop a section that does not apply (a non-code topic has no code examples) rather than padding it.

````markdown
# Learning Guide: {Topic}

**Generated**: {date}
**Sources**: {count} resources analyzed
**Depth**: {brief|medium|deep}

## Prerequisites

## TL;DR

3 to 5 bullets.

## Core Concepts

### {Concept}

{Explanation synthesized across sources.}

## Code Examples

### Basic Example

```{language}
{code}
```

## Common Pitfalls

| Pitfall | Why It Happens | How to Avoid |
|---------|----------------|--------------|

## Best Practices

1. **{Practice}**: {explanation} (Source: {title})

## Further Reading

| Resource | Type | Why Recommended |
|----------|------|-----------------|
| [Title](url) | Official Docs | Authoritative reference |

---

*Generated by /learn from {count} sources. See `resources/{slug}-sources.json` for full source metadata.*
````

## Index: `agent-knowledge/CLAUDE.md` and `agent-knowledge/AGENTS.md`

Both files carry the same content. Add a row per topic; replace the row when a guide is refreshed.

```markdown
# Agent Knowledge Base

> Learning guides created by /learn. Reference these when answering questions about listed topics.

## Available Topics

| Topic | File | Sources | Depth | Created |
|-------|------|---------|-------|---------|
| {Topic} | {slug}.md | {n} | medium | {date} |

## Trigger Phrases

- "How does {topic} work?" -> {slug}.md
- "{Topic} best practices" -> {slug}.md

## Quick Lookup

| Keyword | Guide |
|---------|-------|
| {keyword} | {slug}.md |

## How to Use

1. Check if the user's question matches a topic.
2. Read the guide.
3. Answer from it, and cite it if the user asks for sources.
```

## Sources: `agent-knowledge/resources/{slug}-sources.json`

```json
{
  "topic": "{original topic}",
  "slug": "{slug}",
  "generated": "<ISO 8601 timestamp>",
  "depth": "medium",
  "totalSources": 20,
  "sources": [ { "...": "one record per source, see source-quality.md" } ]
}
```
