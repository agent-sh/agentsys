8 Commands. One Toolkit.

Each works standalone. Together, they automate everything.

/foreman

GitHub issues as a task queue

  • Picks the next ready issue and claims it
  • One worktree subagent per issue, within host capacity
  • Reads Revuto's findings on every PR
  • Lands at the exact head it checked, through the repo's land command
$ /foreman          # Run the queue until nothing is ready
$ /foreman status   # Counts, claims and capacity
$ /foreman 123      # Work one issue

/deslop

Kill AI slop before it ships

  • 3-phase detection: regex, multi-pass analyzers, CLI tools
  • Certainty-graded findings (HIGH / MEDIUM / LOW)
  • JS/TS, Python, Rust, Go, Java
  • Auto-fix HIGH certainty issues
$ /deslop              # Report only (safe)
$ /deslop apply        # Fix HIGH certainty issues

/agnix

Lint agent configs before they break

  • 757 validation rules across 46 categories
  • 10+ AI tools: Claude Code, Cursor, Copilot, Codex, OpenCode, Gemini CLI
  • 125 auto-fixable rules with --fix flag
  • SARIF output for GitHub Code Scanning
$ /agnix                # Validate current project
$ /agnix --fix          # Auto-fix fixable issues

/learn

Research any topic, build a learning guide

  • Progressive discovery: broad to specific to deep
  • Quality-scored sources (authority, recency, depth)
  • Structured guide with examples and best practices
  • RAG index for future agent lookups
$ /learn react hooks --depth=deep   # Comprehensive
$ /learn kubernetes --depth=brief    # Quick overview

/skillers

Learn from your workflow patterns

  • Reads transcripts from Claude Code, Codex, OpenCode
  • Clusters patterns into themed knowledge
  • Suggests skills, hooks, and agents to automate repetitive work
  • No per-turn overhead - works from saved transcripts
$ /skillers            # Analyze workflow patterns
$ /skillers compact    # Compact transcripts into knowledge

/banthis

Durable negative memory

  • Persists banned agent behaviors into CLAUDE.md or AGENTS.md
  • Maintains a managed section with add, list, show, remove
  • Includes init meta-rule so agents invoke it automatically
  • Works project-local or global with explicit flags
$ /banthis "stop ending with vague optional offers"
$ banthis list

/skill-curator

Design reliable SKILL.md files

  • Writes strong trigger descriptions and tight scopes
  • Uses router patterns for broad skills
  • Adds concrete Skip unless gates for pattern rules
  • Keeps skills cross-tool and agnix-ready
$ /skill-curator "create a skill for reviewing background jobs"
$ /skill-curator --improve path/to/SKILL.md

/system-prompt-curator

Design autonomous agent prompts

  • Matches identity to task and tool surface
  • Builds phased workflows with evidence gates
  • Includes realistic error recovery examples
  • Separates prompt guidance from harness checks
$ /system-prompt-curator "GitHub issue resolver"
$ /system-prompt-curator --improve prompt.md --for-orchestrator
